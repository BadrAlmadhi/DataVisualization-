# Pokémon Data Visualization

This project uses D3.js to visualize Pokémon statistics.

## Visualizations

- Attack vs. Defense scatter plot
- Pokémon count by primary type bar chart

## Interactions

- Hover over a Pokémon to view its details
- Click a type bar to filter the scatter plot
- Reset button to restore all Pokémon

## Run the project

```bash
python3 -m http.server 8000
